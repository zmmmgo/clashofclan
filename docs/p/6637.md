## 概述

- 部落都城山顶（Capital Peak）共有 50 座**部落营房**，对应部落最多 50 名成员。
- 营房所有者可自由自定义自己营房的外观。部落营房外观由四种组件自由搭配组合：**屋顶（Roof）**、**外墙（Walls）**、**地面（Ground）**以及**装饰物（Decoration）**。
- 营房组件为纯个性化装饰外观，无论使用何种外观组件，部落营房在战斗中的生命值、判定面积与摧毁率等属性均保持一致。
- 若玩家离开部落并加入新部落，之前配置好的营房外观配置会自动保留并继承到新营房上。若部落未满员，空置的营房将显示为“未入住营房”。
- **营房组件的获取途径**：
  1. **系统默认**：加入部落后即可免费选用基础经典款组件；
  2. **都城声誉解锁**：向都城建筑捐赠都城币提升[都城声誉](/p/6623)等级解锁对应专属组件；
  3. **商人处购买**：在[商人](/p/4583)每周轮换货架中花费突袭奖章或宝石购买；
  4. **限时活动兑换**：在重大主题联动或狂欢活动中花费活动奖章兑换；
  5. **黄金令牌奖励**：在特定月份的黄金令牌免费或付费奖励线中获取；
  6. **史诗宝箱抽取**：从[宝箱](/p/6932)中有概率抽取尚未拥有的营房组件。
